# ТАНЧИКИ (TANKI 2026)

Классическая аркадная игра в жанке «танковый бой», разработанная на Python с использованием библиотеки Tkinter.


## Возможности

- 5 уникальных уровней с различными картами
- Управление танком 
- Стрельба по врагам
- Вражеские танки 
- Разрушаемые кирпичные стены
- Неразрушаемые стальные стены
- Система жизней
- Система очков 
- Сохранение рекордов для каждого уровня
- Защита «Орла»

## Управление

| Действие | Клавиша |
|----------|---------|
| Движение вверх | ↑ (Стрелка вверх) |
| Движение вниз | ↓ (Стрелка вниз) |
| Движение влево | ← (Стрелка влево) |
| Движение вправо | → (Стрелка вправо) |
| Выстрел | Пробел |

## Установка и запуск

1. Убедитесь, что установлен Python 3.13 или выше
2. Скачайте все файлы проекта
3. Установите зависимости (Tkinter встроен в Python, дополнительных библиотек не требуется)
4. Запустите игру через файл main.py
